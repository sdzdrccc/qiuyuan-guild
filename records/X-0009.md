## 起因

## 关键判断（六条）

### 一、现在 = **设计分布式、部署单体**；而 M1 连单体都还没起

上游 §3.1 开篇即定：

> **「逻辑上是分布式的，部署上可以先跑在同一台机器。」**

| 形态 | 内容 |
|---|---|
| **设计态** | **九类进程**（8 个 Go + 1 个 UE DS） |
| **起步态** | **8 合 1** —— 1/2/3/5/6/7/8/9 合并为一个 Go 进程（单体但模块化），只留 4（Scene / DS）独立 |
| **当前实际** | `qiuyuan-dalu/server/` **只有 `.gitkeep`**；M1 = **1 个 Go 进程**（Gateway + Login + Game）+ UE 客户端，**无 DS、零跨进程调用** |

> 上游原话：**「收敛成本，不收敛设计。」**

### 二、现在就要守的纪律 = **四条拆分前提**

上游 §3.1 写进代码规范的第四条是**决定性**的：

| # | 前提 | 拆进程时的作用 |
|---|---|---|
| ① | 禁止全局单例 | 单例是**进程内隐式耦合**，拆时无处安放 |
| ② | 玩家数据不驻留进程内存 | 否则拆开后两边各一份 = **双真源** |
| ③ | 模块间只通过接口通信 | 否则**改动面不可控** |
| ④ | 所有跨模块调用走同一条**内部 RPC 抽象** | **抽象在 → 换网络调用零改动** |

> **第 ④ 条正是 ADR-0014 判 protoc 归 M4 的依据**：「**抽象 ≠ 网络**」—— M1 写 Go interface 即可。

### 三、缺口 A：**服务端进程形态在本仓无落点**

`PROJECT-STRUCTURE.md` §1 里 `server/` **只占一行**；`ROADMAP.md` 管里程碑但**不含进程形态**；而「九类进程 / 起步 8 合 1 / 四条拆分前提 / 分线扩容」**全在上游**，本仓无指针。

→ ADR-0014 裁定 protoc 归 M4 时，依据散落在上游三节，**无本地落点可引**。

### 四、缺口 B：**「服务端重写 Go」从未进过 ADR 台账**（**根因**）

数了 `DECISIONS.md` 索引：ADR-0001 ~ 0014 共 14 条，**没有一条**记载「服务端重写 Go」。该裁决**只活在 `MULTI-AGENT-DEV-PLAN.md` §8.5 的正文里**。

| 项 | 事实 |
|---|---|
| 裁决时间 | **v0.11**（commit `6aa9a05`，2026-09-27） |
| ADR 机制实例化 | **v0.14**（commit `e77661f`） |
| 结论 | **前 ADR 时代的裁决，从未补录** —— 同 `X-0001` 的补记情形 |

> **B 是因，A 是果**：正因为**没有任何一条 ADR 写着「服务端用什么、否决了什么」**，才没人察觉本仓缺一份服务端落点。

### 五、附带发现：一份**已被否决的历史方案**（真源污染 + 编号撞车）

核对时按文件名检索 `find -iname "*技术架构*"`，**精确命中 2 份**：

|---|---|---|

| `F:/zxc/XiaomiMiMoProjects/.mimo-sessions/2026-09-14/…/虬渊大陆-MMORPG技术架构方案.md` | 2026-09-14 18:33 | **Java 单体继承**、UE DS 后置、不微服务化 |

| 冲突项 | 会话版（9-14） | 现行 |
|---|---|---|
| 服务端 | **Java 单体继承** | **Go 重写** |
| 拆分策略 | 「不微服务化」 | 「逻辑分布式」 |

**判定：被否决的旁支，非「现行方案的第二处」** —— 同日上游已有 V1.57 定稿，**v0.11（9-27）裁决「对齐上游定稿 → 重写 Go」，即否决了它**。

**三重风险**：

| # | 风险 | 说明 |
|---|---|---|
| 1 | **检索污染** | 按文件名检索**约一半概率**拿到作废的那份（本次即由此发现） |

| 3 | **隐身性** | **不在 Obsidian 库内** → vault 侧检索看不见，只有文件系统检索能命中 |

### 六、何时变真分布式（**按里程碑对齐，上游按规模**）

| 阶段 | 进程形态 | 触发事件 |
|---|---|---|
| **M1 – M3** | 1 个 Go 进程 | — |
| **M4** | Go + UE DS（**首次两进程**） | 场景服独立、`Scene ↔ Game` 走 gRPC → **此时装 protoc** |
| 小规模上线 | 1 网关 + N 个 DS | 单 DS 装不下 |
| 中期 / 远期 | 网关集群 + 分区 | 商业化 |
