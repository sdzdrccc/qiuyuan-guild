## 关键判断（六条）

### 一、向导现存项只有五个（**实测枚举**）

证据：`Engine/Source/Editor/GameProjectGeneration/Classes/TemplateProjectDefs.h` → `ETemplateSetting`

```cpp
UENUM()
enum class ETemplateSetting
{
	Languages,
	HardwareTarget,
	GraphicsPreset,
	StarterContent UE_DEPRECATED(5.6, "Ability to add Starter Content has been removed"),
	XR,
	Raytracing_DEPRECATED,
	Variants,
	All
};
```

`SProjectDialog.cpp` 实际构造（`if (!HiddenSettings.Contains(ETemplateSetting::X))` 五处）：

| 向导现存项 | 对应原 §3.2 第几项 |
|---|---|
| `Languages` | 第 2 项（Blueprint / C++） |
| `HardwareTarget` | 第 3 项（原写「Target Platform」） |
| `GraphicsPreset` | 第 4 项（Quality Preset） |
| `Variants` | 无（模板未定义变体） |
| `XR` | 无（M1 不做） |

**`StarterContent` 与 `Raytracing` 均已不在向导上** —— 原第 5、6 项**无须操作**。

### 二、第 3 项「Desktop + Mobile」**无法照做**（两项理由）

| # | 理由 | 证据 |
|---|---|---|
| ① | **不可多选** | `HardwareTargetingSettings.h` → `EHardwareClass` **只有 `Desktop` / `Mobile` 两个值**（`Unspecified` 带 `UMETA(Hidden)`）。**没有「Desktop and Mobile」这一项** |
| ② | **性质误读** | 它不是平台开关，是**默认画质档** —— `HardwareTargetingModule.cpp` 按 `bLowEndMobile` / `bAnyMobile` / `bAnyPC` / `bHighEndPC` 等**组合**批量改 `URendererSettings`；`GameProjectUtils.cpp::AddHardwareConfigValues()` 把两个下拉写进 `Config/DefaultEngine.ini` 的 `[/Script/HardwareTargeting.HardwareTargetingSettings]` |

**故 ADR-0010 原句「这是手机端预留最重要的一次点击」不成立。**

### 三、取值定为 `Desktop` + `Scalable`

`Desktop` + `Scalable` 是**合法组合**（源码中 `bAnyPC = (Desktop)` 独立于 GraphicsPreset）——
表明 M1 面向 PC，同时保持保守默认画质（沿用 ADR-0010 第 4 项的实质意图）。

### 四、「手机端预留」的落点**不在创建向导里**

| 层 | 事实 | 证据 |
|---|---|---|
| 平台支持 | **引擎级**，本机**已装** | `ls F:/zxc/UE_5.8/Engine/Platforms/` → `Android` `IOS` `VisionOS` `Windows` |
| 工程限定平台 | `.uproject` 可选字段 `TargetPlatforms`，**向导不写** | `GameProjectUtils.cpp` 创建流程只写 ini；`grep TargetPlatforms` 仅命中插件校验与 `CustomTargetPlatforms` 两处，**非创建流程** |
| → 结论 | **不写 = 全平台开放**（最宽松），故原「勾 Mobile」**无操作、也无必要** | `Templates/TP_Blank/TP_Blank.uproject` 无该字段 |

**手机端预留的实质仍是「约束资产规格 + 抽象输入」**（ADR-0010 §四**不变**，与 `MOBILE-PLAN.md` 一致）。

### 五、路径与命名：**向导无法一次做到「目录 ≠ 工程名」**

向导按 **`<父目录>/<工程名>/`** 建工程（面板即 `Name` + `Location` 两格）。
而本项目要「目录 `ue-client` + 工程名 `QiuyuanDalu`」→ 两条路：

| 路线 | 做法 |
|---|---|
| **A**（GUI） | `Location` 指 `qiuyuan-dalu/`、`Name` 填 `QiuyuanDalu` → 得 `qiuyuan-dalu/QiuyuanDalu/` → **重命名目录为 `ue-client/`** |
| **B**（命令行） | 直接**套用 `Templates/TP_Blank/`** 复制为 `ue-client/`，按 `TemplateDefs.ini` 规则改名 |

**路线 B 的依据**（`Templates/TP_Blank/Config/TemplateDefs.ini`，即向导自己的创建规则）：

| 规则 | 内容 |
|---|---|
| `FoldersToIgnore` | `Media` |
| `FilesToIgnore` | `%TEMPLATENAME%.uproject`（**向导重新生成**）、`Config/TemplateDefs.ini` 等 |
| `FolderRenames` | `Source/TP_Blank` → `Source/<工程名>` |
| `FilenameReplacements` / `ReplacementsInFiles` | 扩展名 **`cpp`/`h`/`ini`/`cs`**，三种大小写（`TP_Blank`/`TP_BLANK`/`tp_blank`）全覆盖 |
| `bIsBlank=True` | **不指定默认地图** → 这是 §3.3 第 3 项「设默认地图」被列为必做的原因 |

> **`TP_Blank/` 内无任何绝对路径**（实测 grep）→ **目录可整体移动 / 重命名**，工程不坏。

### 六、本机引擎启动方式（**环境事实** · 已同步台账 §2.1.2）

| 项 | 本机实况 |
|---|---|
| Epic Launcher | ❌ **未装** |
| `UnrealVersionSelector.exe` | ❌ **不存在**（`find Engine -iname "*VersionSelector*"` 无命中） |

→ **启动与构建一律命令行指定引擎**（`UnrealEditor.exe <uproject>` / `UnrealBuildTool.exe -projectfiles` / `Build.bat`）。
