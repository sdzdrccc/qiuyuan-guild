> **层**：L3 游戏侧（本仓 `contracts/`）　|　**状态**：v0.1 首版（Phase 0）
> **真源**：本文件。`qiuyuan-dalu` 与原型**只读消费，不得建副本**。
> **来源**：从 Codex 原型（已实现至 P2）**提炼**，非从零设计。提炼依据逐条标注。
> **作用范围**：定义**字段、类型、约束、语义** —— **不定义文件格式**。

## 0. 本契约已钉死的两处不一致（重要）

原型里存在**两处自相矛盾**，本契约取**有代码证据**的一方为准，并记为勘误。

### 勘误一：灵根枚举的 5/6/7 顺序

| 说法 | 出处 | 判定 |
|---|---|---|
| `0~7 = 金木水火土风雷冰` | `WorldviewData.ROOT_NAMES`、`CharacterRoot.java`、`SpiritualRoot.cs`、`AttributesCalculator`（mainRoot==5 风系 / ==6 雷系 / ==7 冰系）、`CombatService`（atkRoot==6 雷系破法） | ✅ **权威** |
| `0~7 = 金木水火土雷风冰` | 原型 `docs/03-protocol-and-api.md` 第 113 行 | ❌ **笔误，作废** |

> **证据链**：6 处代码一致（含战斗结算里的硬逻辑），仅 1 处文档不同 → 判文档为笔误。
> 本条**必须**按 `CONVENTIONS.md` §1.1 铁律 2 的体例处理：原型侧更正时**只追加勘误，不改历史**。

### 勘误二：境界索引的上界

| 说法 | 出处 | 判定 |
|---|---|---|
| **9 大境界，索引 `0~8` = 炼气 / 筑基 / 金丹 / 元婴 / 化神 / 炼虚 / 合体 / 大乘 / 渡劫**；共 **42 阶段** | `RealmAttrCatalog.REALM_NAMES` + `REALM_LEVELS = {10,4,4,4,4,4,4,4,4}`（含单测逐阶段校验） | ✅ **权威** |
| `realmIndex(0=炼气...26=造化)` | `GameCharacter.java` 字段注释 | ❌ **过时注释，作废** |

> 「造化」不在 9 境界之内 —— 该注释是旧版残留。

### ⚠️ 待裁决：DB 与代码的**基址**不一致

| 位置 | 基址 |
|---|---|
| `xx_realm_level_config.realm_id` | SQL 注释写 `1=炼气,…9=渡劫` → **1-based** |
| 代码 `REALM_NAMES` 索引 / `realmIndex` | `0~8` → **0-based** |

**两者必有一处需要转换，且当前契约未规定在哪转。**
按 `CONVENTIONS.md` §1.1 铁律 3，本项**标记为 `unknown`**，Phase 1 提炼时**必须裁定并落 ADR** —— 不裁定会长期存在 ±1 的隐性 bug。

## 2. 通用约定

1. **命名**：`xx_` 前缀 + 小写蛇形，**语义清晰、不缩写**（`CONVENTIONS.md` §3.1）。
2. **注释强制**：每表必须有表注释，每字段必须有字段注释（含义 + 取值范围 / 枚举）。
3. **枚举必须留 `unknown`**：凡向后回填的枚举，必须允许「未核实」取值。
4. **定义表 vs 实例表**：
   - `*_defs` / `*_config` = **定义**（策划配置，全服共用，可热改）
   - `xx_inventory` / `xx_drop_items` / `xx_storage_*` = **实例**（玩家资产，逐件独立）
   - **判据**：能被同一个玩家持有多份且各自不同 → 实例表。
5. **属性不落库**：见 §6。

### 3.2 `xx_character_roots`（灵根明细）

| 字段 | 类型 | 语义 | 取值 |
|---|---|---|---|
| `character_id` | BIGINT | → `xx_characters.id` | — |
| `root_type` | INT | **灵根类型** | **`0~7` = 金木水火土风雷冰**（见勘误一） |
| `purity` | DOUBLE | 该灵根纯度 | `0~100` |

**关键语义**：

- **每根独立纯度**（不是角色一个总纯度）。
- **主灵根 = 纯度最高者**（`sort_order = 0`），不是建角时指定的。

| 品级 | 灵根构成 |

| `3` 三灵根 | 3 个五行 |
| `4` 双灵根 | 2 个五行（主 + 副） |

| `6` 变异天灵根 | 1 个风 / 雷 / 冰 |

## 4. 境界体系（**权威定义**）

> 来源：`RealmAttrCatalog`（含 `RealmAttrCatalogTest` 逐阶段校验）。

**9 大境界**（索引 `0~8`）：

| 索引 | 境界 | 阶段数 | 阶段命名 |
|---|---|---|---|
| 0 | 炼气 | **10** | 第 N 层（`1~10`） |
| 1 | 筑基 | 4 | 初期 / 中期 / 后期 / 大圆满 |
| 2 | 金丹 | 4 | 同上 |
| 3 | 元婴 | 4 | 同上 |
| 4 | 化神 | 4 | 同上 |
| 5 | 炼虚 | 4 | 同上 |
| 6 | 合体 | 4 | 同上 |
| 7 | 大乘 | 4 | 同上 |
| 8 | 渡劫 | 4 | 同上 |

**合计 42 个成长阶段。**

**数值生成公式（权威）**：

```
炼气 n 层   = 基准 × 1.18^(n-1)
筑基初期    = 基准 × 5
金丹初期    = 基准 × 5 × 3
其后每大境界 × 3
筑基及以上单阶段成长：初期 → 中期 ×1.25 → 后期 ×1.5625 → 大圆满 ×1.953125
```

**基准值**：`HP=100 / MP=50 / ATK=10 / DEF=5`

**寿元表（按大境界）**：

| 境界 | 炼气 | 筑基 | 金丹 | 元婴 | 化神 | 炼虚 | 合体 | 大乘 | 渡劫 |
|---|---|---|---|---|---|---|---|---|---|
| 寿元上限（年） | 120 | 250 | 500 | 1200 | 3000 | 5000 | 10000 | 20000 | 100000 |
| 衰老（游戏年 / 现实天） | 1 | 2 | 2.5 | 4 | 6 | 10 | 20 | 50 | 100 |

### 4.1 `xx_realm_level_config`（42 阶段基础属性配置）

**权威性**：启动时由 `RealmAttrCatalog` 公式导入 42 阶段，**此后以本表为权威**（GM 可后台调数值）。

### 5.1 本命神通（关键规则）

- **八大灵根各 3 阶**（炼气 / 筑基 / 金丹）= **24 个**。
- ID 格式：**`inn_<root>_<tier>`**（如 `inn_huo_1` = 火系火球术）。
- **仅「主灵根」可施放**（副灵根拒绝），随境界解锁：`炼气=0 / 筑基=1 / 金丹=3`。
- **攻击神通自带元素属性** → 走对应元素攻/抗乘区 + 五行生克（用神通元素 vs **目标主灵根**）。
- **火系积心魔、雷系积狂躁**（三负面来源）。
- **AOE 神通**命中 **14 单位**内所有玩家。
- 客户端快捷键 `Q / E / R`，**随主灵根自动切换**。

### 5.2 功法（`gong_*`）

- 建角按**主灵根**自动习得 1 部：`gong_jin` / `gong_mu` / `gong_shui` / `gong_huo` / `gong_tu` / `gong_feng` / `gong_lei` / `gong_bing`。
- 提供**随等级成长的被动词条**，叠加进属性面板。
- 升级消耗灵力 `baseCost × level`；**等级上限 = `1 + 境界索引×3 + 小阶 - 1`**。

## 6. 属性派生（**不落库**）

> **核心原则**：属性**不落库**，由「**来源字段**」实时派生。属性是**计算视图**。

**来源字段**（均已存在于 `xx_characters`）：境界 + 小阶、体质层级、资质品级、**每根纯度**、主灵根、三负面。

**三级结构**：

| 级 | 内容 |
|---|---|
| 一级 · 基础面板 | 气血 / 灵力 / 物攻 / 法攻 / 神识 / 物防 / 法防 / 命中 / 闪避 / 会心 / 会心伤害 / 会心抗性 / 破防 / 格挡 / 格挡减伤 / 攻速 / 施法速度 / 移速 |
| 二级 · 元素（8 系） | 金木水火土风雷冰 **攻击 + 抗性**，以及**元素穿透** |
| 三级 · 隐藏 / 运营 | 装备评分、修为、灵压、因果 / 气运（**预留，暂不做**） |

### 6.1 来源 → 属性 投放表

| 来源 | 主要投放到 |
|---|---|
| 境界 + 小阶 | 全基础属性 |
| 体质层级 | 气血、物防、格挡、闪避（肉身系） |
| 资质品级 | 法攻、会心、会心伤害（天赋系） |
| **纯度（每根独立）** | 全部攻防 × 主根纯度效率；**副根纯度影响对应元素攻击** |
| **主灵根**（纯度最高者） | 对应元素攻击 **+20%**、对应元素抗性 **+10%**；决定突破 / 生克 / 废体判定 |
| 副灵根 | 对应元素攻击 **+5%**（多灵根；双灵根主 +25% 副 +10%） |
| **三负面** | 心魔 → 法术攻击/施法衰减；狂躁 → 会心波动；丹毒 → 全属性小幅衰减 |
| **生克** | 元素乘区（**不写入面板**，战斗时计算） |

### 6.2 纯度效率的边界（易错）

- 主根纯度 **`<30` → 废体惩罚 `-40%`**
- 主根纯度 **`>80` → 极品拉满**

### 6.3 战斗结算公式（**权威**）

```
命中判定: clamp((攻方命中 - 守方闪避) / 100, 5%, 95%)
会心判定: clamp(攻方会心 - 守方会心抗性, 2%, 60%)
格挡判定: clamp(守方格挡 - 攻方破防系数, 0%, 50%)

基础伤害（物理技能）：
  attack  = 物理攻击 × (1 + 攻方纯度效率)
  defense = 物理防御 × (1 - 攻方破防%) × (1 + 守方纯度效率)
  base    = max(1, attack - defense × 0.8)

基础伤害（法术技能）：同上，物攻/物防 → 法攻/法防

最终伤害 = base
  × 技能倍率
  × 元素乘区：攻方对应系攻击加成 × (1 - 守方对应系抗性) × 生克倍率
  × 会心乘区：命中会心 ? 会心伤害倍率（默认 1.5） : 1
  × 格挡乘区：触发格挡 ? (1 - 格挡减伤) : 1
  × 负面修正：心魔 → 法术 -5%~-15%；狂躁 → 会心伤害 -10%；丹毒 → 全伤害 -5%
  × 随机浮动 0.9~1.1

跨阶修正：大阶差距 ≥ 2 时，元素生克倍率衰减 50%
```

**生克规则**：五行相克 **±20%**；雷**破法 +15%**；冰克火 / 水 / 金。

### 6.4 平衡红线（原型踩坑记录，**契约级约束**）

| 项 | 上限 / 保底 |
|---|---|
| 破防 | **≤ 60%**（防御收益须保底，避免防御贬值） |
| 会心率 | **封顶 60%**；会抗与命中有下限保障 |
| 元素与基础攻击 | **分属不同乘区**，但总量控制（加法池 / 乘法池分离） |
| 三负面 | **不能只有惩罚** —— 须留双刃机制（如心魔 >70 时法术威力 +20% 但可能失控） |

### 7.1 装备槽位

### 7.2 词条键名（**必须与属性面板键名一致**）

```
physAttack / magAttack / physDefense / magDefense
maxHp / maxSpiritPower / shenshi
hit / dodge / crit / critDamage / critResist
armorBreak / block / blockDamage
moveSpeed / attackSpeed / castSpeed
elementPenetration

元素攻 / 抗：elemAtk0~7 / elemRes0~7   ← 下标即灵根枚举（见 §0 勘误一）
```

> **这条是硬约束**：词条键名与面板键名必须**逐字相同**，否则「装备加成后属性」无法自动合并。
> 校验脚本 `check-data.js` 应比对两侧键集合。
