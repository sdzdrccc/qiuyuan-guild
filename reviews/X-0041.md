G-7 首版设想是「README 声明 ↔ 文档头部」**校对判据**；实施时发现 README 把版本号抄了**两份**（仓库内容块 + 底部链接区），校对判据要永远同时维护两处。⇒ 改为**禁抄**：README 一个版本号都不许有，版本只住文档头部。**没有第二份，就无从漂移** —— 比「两边相等」更强也更简单。

1. **`rolesOf` 撞声明**：import 与本地 function 同名 ⇒ 先删本地定义才发现 `SyntaxError` 风险（`node --check` 抓的）。
2. **`executorField` 比 `headerField` 严**：我要求列表前缀必填，而存量 X-0028 无 bullet ⇒ 两处判据口径不一就会造出「C1 说缺、视图说有」的新裂隙（正是 G-9 要治的病）⇒ 统一为 bullet 可选。
