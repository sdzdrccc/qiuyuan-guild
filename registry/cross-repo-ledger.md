# cross-repo-ledger —— 跨库登记台账

> **性质**：**索引视图**，不是正文。**正文永远在 `records/X-*.md`**。
> **一行的义务**：任何**跨库需求 / 交付 / 契约变更**，必须在此登记一行，并指向 `records/` 的正文。
> **查账双向核对**（方案 §6.2）：有索引无正文 = **缺账**；有正文无索引 = **孤儿记录**。
